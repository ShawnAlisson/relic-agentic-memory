**Title:** Relic — Memory for on-call AI agents (CockroachDB × AWS)

**Description:**

Relic is memory for on-call AI agents. Not a chatbot — a database.

When production pages an agent, it forgets everything the moment the process dies. Relic stores the incident, recalls the last time it happened with CockroachDB vector search, acts, and writes the lesson so the next agent never starts from zero.

CockroachDB: Distributed Vector Indexing, Agent Skills, ccloud CLI, Managed MCP.
AWS: S3, Lambda, Bedrock (optional).
